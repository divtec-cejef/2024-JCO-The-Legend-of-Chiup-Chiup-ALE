Description détaillée

Fenêtre principale.

MainFrm représente la fenêtre principale, dans laquelle est placé une instance de GameView. Cette fenêtre gère une instance de GameCanvas, qui est en charge de la cadence du jeu.

Pour changer le titre de la fenêtre, il faut éditer le fichier mainfrm.ui et modifier la propriété windowTitle de l'objet MainFrm.
