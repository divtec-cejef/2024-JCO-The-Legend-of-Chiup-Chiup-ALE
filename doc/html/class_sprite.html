Description détaillée

Classe qui représente un élément d'animation graphique 2D.

Cette classe met à disposition différentes méthodes permettant de gérer simplement un sprite animé.

Un sprite est un élément graphique qui affiche une image bitmap. Cet élément graphique doit appartenir à une scène.

Il possède un certain nombre de propriétés, associées à des méthodes, influençant son apparence et sa position :

  • pos : la position 2D du sprite
  • x : la position sur l'axe horizontal du sprite
  • y : la position sur l'axe vertical du sprite
  • z : l'ordre z du sprite
  • rotation : l'angle de rotation du sprite
  • scale : un facteur de grossissement/rappetissment du sprite
  • opacity : l'opacité du sprite, valeur décimal comprise en 0 et 1, 0 étant transparent et 1 opaque.

Toutes ces propriétés peuvent être animées de façon très simple au moyen d'un objet QPropertyAnimation.

D'autres méthodes permettent de connaître la géométrie et le placement du sprite : width(), height(), posX(), posY(), left(), right(), top(), bottom(). Il est possible d'obtenir le rectangle dans lequel le sprite est inscrit avec globalBoundingBox(). Il est possible d'obtenir la forme exacte du sprite avec globalShape().

L'apparence du sprite n'est déterminée que par une seule image. Toutefois, il est possible d'en mémoriser plusieurs, afin de changer facilement d'apparence. Il est également possible de faire changer automatiquement ces images dans le but d'obtenir un sprite animé.

La méthode addAnimationFrame() permet d'ajouter une image au sprite. Si plusieurs images sont ajoutées, elles sont conservées dans une liste qui préserve l'ordre d'ajout des images.

La méthode setCurrentAnimationFrame() permet de spécifier quelle image doit être affichée (l'indice de la première image est 0). La méthode currentAnimationFrame() indique quelle image est actuellement affichée par le sprite.

La méthode startAnimation() permet de démarrer l'animation des images. La méthode stopAnimation() permet de stopper l'animation des images, soit immédiatement (IMMEDIATE_STOP) soit à la fin du cycle (END_OF_CYCLE_STOP). La vitesse d'animation peut être réglée avec setAnimationSpeed() ou au moment de démarrer l'animation.

Il est également possible de demander au sprite d'émettre un signal chaque fois que l'animation est terminée, avec la méthode setEmitSignalEndOfAnimationEnabled(). Cela permet par exemple de connecter ce signal au slot deleteLater() du même objet, afin de détruire automatiquement le sprite dès que l'animation est terminée (par exemple pour afficher une explosion).

Il est possible de démarrer l'animation pour un seul cycle d'animation avec la méthode startAnimationOnce().

Pour changer complètement l'image affichée par un Sprite, il faut effacer la liste des images avec clearAnimationFrames() puis ajouter l'image de la nouvelle apparence avec addAnimationFrame().

Comme la classe Sprite spécialise la classe QGraphicsPixmapItem, qui elle-même spécialise la class QGraphicsItem, toutes les méthodes de QGraphicsItem sont accessibles au sprite.

Intéger un sprite à une scène

Lorsqu'un sprite est créé, il faut le placer sur une scène pour qu'il apparaisse, au moyen de la méthode GameScene::addSpriteToScene(). Celle-ci en prend alors la propriété et se chargera de la détruire lorsque la scène sera détruite.

Une fois ajouté à la scène, il est possible de l'abonner au tick afin qu'il reçoive la cadence du jeu, grâce à la méthode GameScene::registerSpriteForTick(). Dès qu'un sprite est abonné à la cadence, sa méthode virtuelle tick() est automatiquement appelée.

Attention : si le sprite est détruit, il faut s'assurer au préalable de le désabonner avec GameScene::unregisterSpriteFromTick().

Avant d'être détruit, un sprite émet le signal spriteDestroyed().

Positionnement du sprite

Lorsqu'un sprite est positionné sur la scène au moyen de setPos(), c'est en réalité le coin supérieur gauche du sprite qui est positionné à la coordonnée donnée.

Ce point de positionnement, appelé aussi hotspot, peut être déplacé avec la méthode setOffet().

Cela permet par exemple de positionner le sprite avec son centre plutôt qu'avec son coin supérieur gauche.

Transformation du sprite

Il est possible d'appliquer une transformation sur le sprite, par exemple pour le tourner, changer sa taille ou appliquer un effet miroir avec les méthodes setRotation() et setScale().

Si des transformations plus complexes doivent être réalisées, la méthode setTransformations() permet d'appliquer une liste de transformations à un sprite.

Le point de transformation peut être défini avec setTransformOriginPoint().

Le gestionnaire de cadence

Un sprite peut être déplacé de plusieurs façons différents au sein d'une scène.

Une première solution est qu'un élément externe se charge de la position d'un sprite en utilisant les propriétés publiques du sprite, telle que x (setX()), y (setY()) et z (setZ()) ou la fonction setPos().

Une autre solution est de laisser le sprite gérer seul son déplacement en se basant sur la cadence du jeu.

Pour faire cela, il suffit d'attribuer au sprite un gestionnaire de cadence (SpriteTickHandler()) qui contiendra le code nécessaire pour faire bouger le sprite.

Si un gestionnaire de cadence est attribué au sprite, à chaque tick, le gestionnaire de cadence est appelé (tick()).

Une dernière solution est de spécialiser la classe Sprite afin de surcharger la méthode tick().

Les listes d'animation

Par défaut, un sprite possède une seule liste d'animation (d'indexe 0), sur laquelle les méthodes addAnimationFrame(), startAnimation(), clearAnimationFrames(), etc. agissent.

Il est possible d'ajouter autant de listes d'animation que nécessaire. Par exemple, s'il faut une animation différente selon que le sprite monte, descend, va à droite ou à gauche, il est possible d'ajouter trois listes d'animation supplémentaires.

Pour ajouter une liste d'animation, utiliser la méthode addAnimation(). Pour rendre une liste d'animation active, utiliser la méthode setActiveAnimation() en indiquant en paramètre l'index de la liste à activer. Lorsqu'une liste d'animation est activée, toutes les méthodes mentionnées au début de cette section agissent sur la liste active.

clearAnimations() efface toutes les listes d'animation et recréé une liste par défaut, vide.
